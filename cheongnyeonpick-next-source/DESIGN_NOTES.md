# 청년픽 NEXT UI 개편

## 방향과 확인 범위

제공된 21쪽 레퍼런스 보고서를 읽고, UI Bowl의 공개 웹사이트 목록 259개와 공개 미리보기(영상 프레임 포함)를 대조했다. 핵심 24개 자료는 확대 검토했다. 로그인·유료 패턴 및 각 외부 서비스의 모든 내부 동작을 검증한 범위는 아니다.

라임·라벤더·살구색, 굵은 글자, 작은 스티커, 티켓의 절취선과 오프셋 그림자를 공통 언어로 삼았다. 검색·조건·서류의 본문은 차분한 종이 패널로 구성한다. 참고 서비스의 로고·캐릭터·이미지·완성 화면을 제품에 복제하지 않았다.

## 적용 조합

| 화면 | 참고한 구성 원칙 |
| --- | --- |
| 홈 | 토스 비즈니스·braintrust·DashLite: 내 조건 → 현황 → 다음 행동 → 추천 |
| 정책 찾기 | 원티드·점핏·링커리어: 목적 진입, 적용 조건, 지역·학적·모집 필터 |
| 정책 비교·상세 | 카드고릴라·토스페이먼츠·KRDS: 항목별 대응, 공고 기준·내 정보·결과·근거 |
| 생활변화 | 트립닷컴·카드고릴라: 지역·학적·취업을 따로 가정하고 변경 항목 비교 |
| 신청 준비 | 스티비·아치캘린더·듀오링고: 단계별 다음 행동, 목표일, 제출 상태 분리 |
| 전자지갑 | 클로바노트·네이버페이: 문서 목록·상세·발급 방식·정책별 사용 관계 |
| AI 내비게이터 | Perplexity·뤼튼: 질문 예시, 참고한 조건, 근거 상태, 실제 작업 이동 |
| 브랜드 | 오롤리데이·요즘사·여기어때 디자인 라이브러리: 제한된 색, 고유 N 도형, 일관된 토큰 |
| 공통 탐색 | 삼성생명다이렉트·국가유산디지털서비스·호갱노노·클로브 AI: 목적 진입, 분야 아이콘, 생활권 분리, 요약과 작업 연결 |

## 기능과 데이터

기존 최신 버전의 전자지갑 검색, 소득 서류 안내, 확인 기록과 내정보 우측 전자지갑을 유지했다. 내 문서 보관은 IndexedDB, 메타데이터·저장 정책·목표일·제출 본인 확인 기록은 브라우저 저장소를 사용한다. 직접 보관 문서는 발급기관·유효성 검증 전으로 표시한다. 보관 해제한 문서는 복원할 수 있다.

카카오·네이버는 미연결로 표시하며 실제 인증·문서 가져오기는 실행하지 않는다. AI는 외부 전송 없는 규칙 기반 시연이다. 개별 공고 원문과 실시간 생성형 AI가 연결되었다고 주장하지 않는다. 정책 3개는 기존 시연 예시를 유지하며 실제 금액·모집일·자격 판정을 만들지 않는다.

준비 점검 100%와 공식 제출 여부의 본인 확인 기록을 분리한다. 생활변화의 가정은 실제 프로필을 변경하지 않는다. 개인정보·실제 문서 바이트는 서버 소스에 포함하지 않는다.

## 확인 결과

- 주요 7개 화면을 320·390·768·1024px 프레임에서 점검: 문서 전체의 가로 넘침 없음. 모바일 AI 패널·하단 탐색 확인.
- 내정보 유효성 검사·저장 후 재열기, 정책 검색·빈 결과·조건 초기화·저장·2개 정책 비교 확인.
- 생활변화 가정 비교가 실제 내정보를 변경하지 않음을 확인.
- 준비 점검 100%와 제출 본인 확인 기록 분리, 목표일 달력 반영·삭제·재열기 확인.
- 지갑 소득 서류 검색·발급 안내·확인 기록 재열기 확인. 파일 직접 보관·다운로드 바이트 일치·정책 연결·보관 해제·복원·재열기 확인.
- AI 대화의 내조건 표시, 생활권 질문의 조건 표 이동, 생활변화 질문 해석 확인.
- 점검 중 찾은 필터 초기화 순서 및 지갑 탭 변경 시 업로드 버튼 중복 문제 수정.
